# LP 食品配方演示器 · LP Food Formulation Demo

[English](./README.en.md) · **在线页面**：<https://yuxuanlongbeyond.github.io/lp-food-demo/>

同一个精确求解引擎的两个出口：**G1 方便面调料包减钠** ＋ **G2 植物蛋白混配**。两阶段单纯形法、Bland 规则防循环、全程 **BigInt 精确分数**（与原算例 Python `fractions` 同口径）——页面上的每个数字都是实时精确求解出来的，不是从文档抄来的。零第三方依赖、零构建步骤。

> **演示级**：文献/示意系数＋精确求解，只用于讨论方向与量级。不构成营养或医疗建议，不可当商业报价。详见[口径与免责](docs/caliber-zh.md)。

这是个人战略库《00-个人战略：十年饮食健康事业总路线》W1–2 的交付物（v0.1.0，2026-10-23 发布），把战略要求的「LP 三件武器」（最优性证明 / 影子价格 / 灵敏度）第一次产品化成可交互页面。

## G1 · 方便面调料包减钠

100g 调味料，五原料（NaCl / KCl / 味精 / 酵母抽提物 / 载体），约束：总重=100、咸度≥12、鲜度≥2、钠≤Ncap、KCl≤8g。求最低成本。

| 钠档 Ncap (mg/100g) | 4716 | 4100 | 3500 | 3000 | **2608** |
|---|---|---|---|---|---|
| 成本 (¥/100g) | 0.3020 | 0.3189 | 0.3352 | 0.3489 | **0.3596** |
| 对 LP 解基线 (¥/吨) | 0 | +168 | +332 | +469 | **+576** |
| 对纯盐基线 (¥/吨) | +188 | +357 | +520 | +657 | **+764** |
| 折 8g 包（厘，对 LP / 对纯盐） | 0 / 1.5 | 1.3 / 2.9 | 2.7 / 4.2 | 3.7 / 5.3 | **4.6 / 6.1** |

（基线差额为求解器精确值取整；页面按一位小数实时显示。基线本身也不是纯盐：4716 档 LP 解为 NaCl 11.36 / KCl 0.85 / 味精 2 / 载体 85.79，因味精自带钠 125mg/g，不掺 KCl 压不到 4716。）

- **2608 天花板**：KCl 顶格 8g 时钠的算术下限，顶点配方 NaCl 6 / KCl 8 / 味精 2 / 载体 84，钠 = 393×6+125×2 = 2608 精确贴线；2600 不可行。
- **影子价格**：精确值 161/5895000 ≈ **¥27.31/吨·100mg**（放宽钠 100mg 约省 ¥27.31/吨），在 4100→2608 全程恒定；与中心差分数值验证一致。对外口径沿用战略文档的「¥27（区间 27.2–27.6）」。
- **双基准并报**（口径纪律之二）：对 LP 解基线 0.3020（+¥576/吨·4.6 厘）与对纯盐基线 0.2832（+¥764/吨·6.1 厘）两个口径同时常驻页面，随滑杆联动。

## G2 · 植物蛋白混配

100g 蛋白基料，七原料（大豆分离蛋白 / 豌豆蛋白 / 大米蛋白 / 赖氨酸盐酸盐 / DL-蛋氨酸 / 苏氨酸 / 麦芽糊精），9 项必需氨基酸按 FAO 2013 模式（成人 / 学龄前）约束，AAS≥1 或 DIAAS≥1（需求×1.1），植物蛋白上限 SPI≤60%。

| 情景 | 含义 | 成本 (¥/100g) | 折 ¥/kg 蛋白 |
|---|---|---|---|
| S0 | 纯 SPI 基线 | 1.6622 | 20.78 |
| S1 | 成人 AAS 全达标 | 1.7720 | 22.15* |
| S2 / S2′ | 学龄前 AAS（升级免费，S2=S2′ 同价） | 1.7720 | 22.15* |
| S3 | DIAAS 口径（晶体氨基酸入场） | 1.7776 | 22.22 |
| S3′ | DIAAS 且禁用晶体 | **不可行** | — |

*LP 证实三情景同价（豌豆/大米同价 ¥20、同蛋白 0.8，可互换——多重最优）；文档顶点配方另经可行性+等成本独立验证 ⇒ 最优。

**三笔差价**（媒体线口径，随价格实时联动）：

| 升级项 | 差价 |
|---|---|
| 学龄前 AAS（相对成人） | **0**（免费） |
| DIAAS 口径升级（晶体入场，共 0.845g） | +5.57 厘/100g ≈ **¥56/吨** |
| 豆腥/过敏原分散（SPI≤60%） | +109.78 厘/100g ≈ **¥1098/吨** |

豆腥分散的成本是 DIAAS 升级的 **≈20 倍**——贵在感官，不在营养。这是本算例最重要的商业结论。

S3 贴线细节：Lys/SAA/Thr 三关同时 supply=demand（5016/2728/2992mg，比值精确=1），晶体用量 Lys·HCl 0.708 / DL-Met 0.085 / L-Thr 0.053g；游离碱折算系数 Lys·HCl ×14619/18265（≈0.800383）全部精确分数处理。

## 口径纪律三件套（战略 W1–2 验收项）

1. **溯源标签＋证据分级**：每个系数字段带「来源＋检索日期＋待标定」；演示级（文献系数＋小样本自测，只作方向信号）与生产级（专业感官 panel ≥30 或校企数据）分级标注。页面 G1/G2 各有完整溯源表。
2. **双基准并报＋示意价格口径随附**：见上文 G1；两页所有价格均为 2026-10-22 公开渠道检索的示意口径（ChemicalBook / 1688 / 阿里国际站 / Mysteel / 嘉博智汇），随市场变动。
3. **敏感性滑杆**：KCl 价格（2–30）、KCl 咸度等效系数（0.5–0.95）、G2 七原料价格＋两个预设（Met 暴涨 23.5→52：S2 价格纹丝不动；吨级采购豌豆/大米→¥15：S2 进 ¥15.5/kg 带）。

**1+6 全约束形状**：GB 28050「1＋6」强制标识营养素中，钠为已验证主约束（本页可解）；其余 6 项（能量/蛋白/脂肪/饱和脂肪/碳水/糖）在数据 schema 中以显式「示意占位·待标定」占位——结构就位、不伪造精度。详见 [docs/caliber-zh.md](docs/caliber-zh.md)。
