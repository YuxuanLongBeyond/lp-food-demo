# LP 食品配方演示器 · LP Food Formulation Demo

[English](./README.en.md) · **在线页面**：<https://yuxuanlongbeyond.github.io/lp-food-demo/>

同一个精确求解引擎的两个出口：**G1 方便面调料包减钠**（v0.2 扩盘 5→12 原料）＋ **G2 植物蛋白混配**（v0.2 扩盘 7→10 原料、USDA FDC 逐格数据）。两阶段单纯形法、Bland 规则防循环、全程 **BigInt 精确分数**（与原算例 Python `fractions` 同口径）——页面上的每个数字都是实时精确求解出来的，不是从文档抄来的。零第三方依赖、零构建步骤；约束装配数据驱动（G1/G2 共用内核，加原料＝改 JSON 不改代码）。

> **演示级**：文献/示意系数（v02 档为权威数据直录）＋精确求解，只用于讨论方向与量级。不构成营养或医疗建议，不可当商业报价。详见[口径与免责](docs/caliber-zh.md)。

这是个人战略库《00-个人战略：十年饮食健康事业总路线》W1–2 的交付物（v0.1.0 / v0.2.0 / v0.2.1 / v0.2.2，2026-10-23 发布），把战略要求的「LP 三件武器」（最优性证明 / 影子价格 / 灵敏度）产品化成可交互页面。

## 快速开始

```bash
# 1) 跑测试：21 项断言（12 项 v0.1 经典锚点全保留＋9 项 v0.2 引擎生成锚点）
node --test tests/verify.test.mjs        # → 21 pass

# 2) 本地打开页面（fetch 需要 HTTP，不能 file:// 直开）
python3 -m http.server 8000
# 浏览器访问 http://127.0.0.1:8000/
```

生产使用无任何依赖安装步骤：静态文件，任意 HTTP 服务器可托管。

## G1 · 方便面调料包减钠

**经典 5 料盘**（NaCl / KCl / 味精 / 酵母抽提物 / 载体；v0.1 已审计口径）：

| 钠档 Ncap (mg/100g) | 4716 | 4100 | 3500 | 3000 | **2608** |
|---|---|---|---|---|---|
| 成本 (¥/100g) | 0.3020 | 0.3189 | 0.3352 | 0.3489 | **0.3596** |
| 对 LP 解基线 (¥/吨) | 0 | +168 | +332 | +469 | **+576** |
| 对纯盐基线 (¥/吨) | +188 | +357 | +520 | +657 | **+764** |
| 折 8g 包（厘，对 LP / 对纯盐） | 0 / 1.5 | 1.3 / 2.9 | 2.7 / 4.2 | 3.7 / 5.3 | **4.6 / 6.1** |

- **2608 天花板**：KCl 顶格 8g 时钠的算术下限（393×6+125×2 精确贴线），2600 不可行。
- **影子价格**：精确值 161/5895000 ≈ **¥27.31/吨·100mg**，在基不变区间 [2608, **4966**] 内恒定（4966＝393×12+125×2，KCl 退出基的精确拐点）；对外口径沿用「¥27（区间 27.2–27.6）」。

**扩展 12 料盘**（§3.4「可扩变量」：I+G / 柠檬酸 / 蘑菇粉 / 海带粉 / 香辛料 / 乳酸钾掩蔽 / 白砂糖）——四段精确参数化曲线，四条技术路线在不同钠价区间依次启用：

| 钠区间 (mg/100g) | 影子价格 (¥/吨·100mg) | 启用的路线 |
|---|---|---|
| [2612, 4716] | 27.31 | KCl 替代（与经典盘同段） |
| [2378.25, 2612] | 41.71 | I+G 置换 MSG（鲜味省钠） |
| [1641.375, 2378.25] | 78.20 | 乳酸钾掩蔽放松 KCl（8→10.5g） |
| [1494, 1641.375] | 95.17 | 柠檬酸酸提咸（可行下限 1494 精确） |

**病种模式**（换右端项演示，折算为演示假设）：高血压档（钠 ≤1875，食养指南 2000mg/日 × 8g 包 7.5% 份额）经典盘不可行、**扩展盘可解**（0.4299 ¥/100g）——扩盘解锁更低钠档；CKD 控钾档（钾 ≤3000）**不可行**：KCl 与乳酸钾都带钾，控钾直接挤压代盐路线（临床口径 CKD 慎用低钠盐），如实输出。**1+6 开关**（GB 28050）：演示档六行全松；GB 声称档（无糖 0.5g）与甜味下限冲突 → 不可行，诚实展示 ε-约束的形状。

## G2 · 植物蛋白混配

**v01 档**（文献典型值，v0.1 已审计口径，七原料）：

| 情景 | 含义 | 成本 (¥/100g) | 折 ¥/kg 蛋白 |
|---|---|---|---|
| S0 | 纯 SPI 基线 | 1.6622 | 20.78 |
| S1 | 成人 AAS 全达标 | 1.7720 | 22.15* |
| S2 / S2′ | 学龄前 AAS（升级免费） | 1.7720 | 22.15* |
| S3 | DIAAS 口径（晶体入场 0.845g） | 1.7776 | 22.22 |
| S3′ | DIAAS 且禁用晶体 | **不可行** | — |

*LP 证实三情景同价（豌豆/大米等价——交替最优，页面有检测提示）；文档顶点配方另经可行性+等成本独立验证 ⇒ 最优。豆腥分散 +109.78 厘 ≈ **¥1098/吨**，是 DIAAS 升级（+5.57 厘 ≈ ¥56/吨）的 **≈20 倍**——贵在感官，不在营养。

**v02 档**（USDA FDC 逐格＋FAO 2013 Table 5 原模式＋分项消化率，十原料：＋谷朊粉/酵母蛋白/葵花籽蛋白）：

| 情景 | 成本 (¥/100g) | 关键变化 |
|---|---|---|
| S0 | 1.2067 | **谷朊粉（¥9/kg）改写基线**：SPI 33.33＋谷朊粉 66.67，折蛋白 ¥15.08/kg |
| S1 | 1.4725 | FAO 2013 成人 Lys 48＋小麦 Lys 22 → **赖氨酸成硬约束**，Lys·HCl 晶体进场、Lys 贴线 |
| S2 = S3 | 1.4777 | 同一顶点在 AAS/分项消化率两口径下均为最优（DIAAS 升级差价＝0） |
| S2′ / S3′ | **不可行** | USDA 逐格后纯混配达幼儿级被推翻——数据口径改变结论 |

质量前沿（ε-约束）：v02 档 S2 可把九项 AAS 同推到 λmax＝563/512≈**1.0996**（¥2.04/100g），曲线由页面实时绘制。

## 三件武器的完成态（v0.2）

1. **最优性证明**：精确分数顶点＋交替最优检测（v01 S1 为真：豌豆/大米等价顶点；页面明确提示）。
2. **影子价格表**（全约束对偶报告）：每行 LHS/RHS、贴线/松弛、影子价格、**RHS 基不变区间**——区间端点即换基拐点。
3. **灵敏度**：滑杆之外，新增**价格临界点**（「涨到多少换料／降到多少入选」，终局表精确 ranging＋±0.01 元复解探针验证配方是否真变）、**G1 参数化曲线**（上述四段）、**G2 质量前沿**。

## 口径纪律三件套（战略 W1–2 验收项）

1. **溯源标签＋证据分级**：每个系数字段带「来源＋检索日期＋待标定」；v0.2 新增 USDA FDC 逐格值（FDC ID＋检索日期直录）与 FAO 2013 原报告直录；演示级/生产级分级不变。
2. **双基准并报＋示意价格口径随附**：G1 页常驻；两页价格均为公开渠道示意口径（ChemicalBook / 1688 / 阿里国际站 / Mysteel / 嘉博智汇 / USDA FDC），随市场变动。
3. **敏感性**：滑杆＋预设（Met 暴涨、吨级采购、谷朊粉行情）＋上述武器面板。
