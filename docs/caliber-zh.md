- **NaCl 钠含量 393 mg/g**：化学计量（Na 22.99/58.44 ≈ 39.3%）——唯一「非待标定」的技术系数。

## 2. 三件套之二：双基准并报＋单位换算口径

G1 页常驻两个成本基准，随滑杆联动：

- **对 LP 解基线**（Ncap=4716 档最优成本 0.3020 ¥/100g）：回答「减钠这一步本身多贵」——五档 0 / +168 / +332 / +469 / +576 ¥/吨；
- **对纯盐基线**（NaCl 12g＋载体 88g，成本 0.2832 ¥/100g）：回答「和行业常规比多贵」——五档 +188 / +357 / +520 / +657 / +764 ¥/吨。

**单位换算**（`unit_conversions` 字段，全页面统一）：

| 从 | 到 | 乘数 |
|---|---|---|
| ¥/100g | ¥/吨 | ×10 000 |
| ¥/100g | 厘/8g 包 | ×80（¥→厘 ×1000，100g→8g ×0.08） |
| ¥/100g（G2） | ¥/kg 产品 | ×10 |
| ¥/kg 产品（G2） | ¥/kg 蛋白 | ÷0.08（每 100g 基料含蛋白 8g 口径） |

G2「折蛋白」分母为**蛋白含量 8g/100g 基料**的口径（S0 20.78、S3 22.22 由此而来），与「每 g 蛋白成本」的其他行业口径不可直接混比。

## 4. 「1+6」全约束 schema（GB 28050）

GB 28050 强制标识「1＋6」：钠＋能量/蛋白质/脂肪/饱和脂肪/碳水化合物/糖。`data/g1-seasoning.json` 的 `schema_1plus6` 字段把七项全部建为可切换约束结构：

- **钠**：全系数已验证，本页可解（主约束）；
- **其余 6 项**：系数显式标注「示意占位·待标定」，结构就位但默认不参与求解——演示「多目标/ε-约束」形状而不伪造精度。
